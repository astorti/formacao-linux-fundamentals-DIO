Introdução ao Sistema Operacional Linux

Conceitos de Sistema Operacional

  • Kernel: faz a ponte entre o usuário e o hardware; não possui ambiente gráfico.
  • Sistemas Operacionais Domésticos: Linux, Microsoft Windows e macOS.
  • Sistemas Operacionais Servidores.

Linux

  • Muito utilizado no segmento de servidores e por desenvolvedores.
  • Desenvolvido por Linus Torvalds.
  • Inspirado no Unix.
  • Mantido por uma comunidade internacional e pelo ecossistema Linux.
  • Utiliza ambiente gráfico ou terminal para acessar o kernel.
  • Possui diversos ambientes gráficos, como GNOME e KDE Plasma.
  • Distribuições: consistem em um kernel Linux acompanhado de aplicativos e ferramentas específicas, mantidos por empresas ou comunidades.

Principais distribuições

  • Debian, Ubuntu, Red Hat, Fedora, SUSE, entre outras.

Sistemas Embarcados

  • Android, Raspberry Pi, televisões, smartwatches, entre outros.

Modelo Cliente-Servidor

  • Servidor: fornece um recurso ou serviço, como site ou banco de dados, através de um sistema operacional de servidor.
  • Cliente: solicita o serviço através de um sistema operacional desktop ou outro cliente de rede.

Máquinas virtuais

  • Instalação do Ubuntu Server em máquina virtual.

Acesso Remoto a Máquinas Linux

  • Obter o IP: ip a
  • Acessar remotamente: ssh nome-do-usuario-maquina-virtual@ip-da-maquina-virtual

Comandos Iniciais

  • reboot
  • date
  • clear ou Ctrl + l
  • systemctl poweroff

Trabalhando com Arquivos

Navegação de Diretórios

  • pwd: informa o diretório atual.
  • cd /: acessa o diretório raiz.
  • cd ~: acessa o diretório do usuário.
  • ls: lista diretórios e arquivos.
  • cd nome_diretorio: avança para um diretório.
  • cd nome_diretorio/nome_diretorio: avança dois diretórios.
  • cd ..: volta um diretório.
  • cd ../..: volta dois diretórios.
  • Dica: Tab completa nomes ou mostra possibilidades.

Filtrar a Exibição de Arquivos

  • ls | more
  • ls nome_do_diretório/arquivo
  • ls *
  • ls a*
  • ls nome-do-arquivo[1-5]*
  • ls nome-do-arquivo[1,3,5]*
  • ls nome-do-arquivo[^1,5]*

Criar um Arquivo

touch nome-do-arquivo.extensão

Exemplo: touch teste.txt

Busca de Arquivos

  • ls /nome-da-pasta/nome-arquivo
  • ls /nome-da-pasta/arquivo*
  • find -name "nome-do-arquivo"
  • find -name "nome-do-arquivo*"

Criar Diretórios

  • mkdir novo-diretório
  • mkdir "novo diretorio"
  • mkdir novo-diretorio1 novo-diretorio2
  • mkdir /home/diretorio/novo-diretorio
  • mkdir /home/diretorio/diretorio/novo-diretorio

Remover Diretórios

  • rmdir nome-do-diretorio
  • rmdir "nome do diretorio"
  • rmdir diretorio1 diretorio2

Remover Arquivos

  • rm nome-do-arquivo
  • rm *.extensão
  • rm arquivo*

Edição de Arquivos

vi

  • vi nome-do-arquivo
  • i: editar
  • Esc: sair do modo de edição
  • :: comandos
  • w: salvar
  • q: sair

nano

  • nano nome-do-arquivo
  • Ctrl + o e Enter: salvar
  • Ctrl + x: sair

Comando history

  • history: exibe comandos.
  • history 30 / history 5: quantidade específica.
  • !50: executa o comando 50.
  • !!: executa o último comando.
  • !?teste?: executa o último comando que contém “teste”.
  • history | grep "install": filtra o histórico.
  • export HISTTIMEFORMAT="%c ": exibe data e hora.

Trabalhando com Usuários

Criando e Excluindo Usuários

  • useradd username
  • useradd username -m -c "Nome Completo"
  • passwd username
  • chsh -s /bin/bash username
  • useradd username -m -c "Nome Completo" -s /bin/bash
  • userdel -r -f username

Editando Informações do Usuário

  • usermod username -c "Nome Completo"
  • passwd username -e data
  • passwd username -e

Scripts

  • Extensão: .sh
  • Shebang: #!/bin/bash
  • chmod +x nome-do-arquivo.sh
  • ./nome-do-arquivo.sh

Prática: create_users.sh

Grupos de Usuários

  • cat /etc/group
  • usermod -g grupo1 username
  • usermod -G grupo1,grupo2 username
  • usermod -G grupo1,grupo2,novo-grupo username
  • gpasswd -d username grupo1
  • groupadd nome-do-grupo
  • groupdel nome-do-grupo

Sistemas de Permissões

  • Arquivos iniciam com -; diretórios com d.
  • r: read (leitura), w: write (escrita), x: execute (execução).
  • Proprietário, grupo e outros possuem conjuntos independentes de permissões.
  • rwx=7, rw-=6, r-x=5, r--=4, ---=0.
  • chmod 760 /diretorio-ou-arquivo
  • chmod +x exemplo1.sh
  • chmod -x exemplo1.sh
  • chown username2:group2 /diretorio/

Gerenciamento de Discos

Discos e Sistemas de Arquivos

  • HD e SSD.
  • macOS: HFS.
  • Unix/Linux: Ext3, Ext4, XFS.
  • Windows: FAT32, NTFS.

Partições

  • Disco 1: sda
  • Disco 2: sdb
  • Partições: sda1, sda2, sdb1, sdb2, etc.

Visualizar Discos

  • lsblk
  • fdisk -l

Particionar e Formatar

fdisk /dev/nome-do-disco

Exemplo: fdisk /dev/sdb

  • n: nova partição
  • p: partição primária
  • 1: número da partição
  • Enter: primeiro setor padrão
  • Enter: último setor padrão
  • w: salvar

mkfs.ext4 /dev/sdb1

Montar e Desmontar

  • mkdir /mnt/disco2
  • mount /dev/sdb1 /mnt/disco2
  • umount /dev/sdb1

Montagem Automática

  • mkdir /disk2
  • Editar /etc/fstab.
  • Adicionar: /dev/sdb1 /disk2 ext4 defaults 0 0

Copiando Arquivos e Manipulando Processos

Copiar Arquivos e Diretórios

  • cp /home/usuario/Downloads/nome-do-arquivo /home/usuario/Documentos
  • cp ./Downloads/nome-do-arquivo ./Documentos
  • cp ./Downloads/*.txt ./Documentos
  • cp ./Downloads/relatorio* ./Documentos
  • cp -i ./Downloads/nome-do-arquivo ./Documentos
  • cp ./Downloads/* ./Documentos
  • cp -r ./Downloads/* ./Documentos
  • cp -v ./Downloads/* ./Documentos

Mover ou Renomear

O comando mv move arquivos e diretórios sem necessidade de -r.

  • mv -i -v ./Downloads/Arquivos ./Documentos
  • mv ./Documentos/arquivo1.txt ./Documentos/arquivo2.txt
  • mv arquivo1.txt arquivo2.txt

Processos

ps aux: lista processos em execução, incluindo processos de diferentes usuários e processos sem terminal associado.

Servidores de Arquivos com Linux

Samba

  • Instalação do Samba.
  • Criação da pasta publica no disk2.
  • Configuração de permissões.
  • Editar /etc/samba/smb.conf.
[publica]
writable = yes
guest ok = yes
guest only = yes
  • systemctl restart smbd
  • systemctl status smbd
  • systemctl enable smbd
  • Acesso: \\numero-do-ip-do-servidor\nome-da-pasta-publica

Servidores Web com Linux

Apache

  • Instalação: apt install apache2
  • Status: systemctl status apache2
  • IP: ip a
  • O navegador pode acessar o endereço IP do servidor.
  • Página padrão: /var/www/html/index.html.
  • Pode ser necessário liberar HTTP no firewall.

Servidores de Banco de Dados com Linux

  • Instalação do MySQL Server: apt install mysql-server

    • Após a instalação, o MySQL Server já está disponível para uso
